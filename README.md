# 🛡️ ScamShield
### Smart Phishing Message Detection System

ScamShield is a Python-based project that
detects potentially suspicious and phishing
messages using keyword analysis.

## Features
- Suspicious keyword detection
- Suspicious link detection
- Risk score calculation
- Risk level classification
- Scan history

## Technologies Used
- Python
- String Processing
- Conditional Statements
- Functions
- Lists

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the terminal.
4. Run:

python scamshield.py

## Risk Levels
- LOW RISK
- SUSPICIOUS
- HIGH RISK

## Disclaimer
This is a basic rule-based detection system.
It cannot guarantee detection of all scams.
